# Count voice clips

The eight WAV files in this folder say only “one” through “eight”. They were generated offline with [Piper](https://github.com/OHF-Voice/piper1-gpl) 1.8.0 and the [en_US-kristin-medium voice](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/kristin/medium). The voice model card identifies its LibriVox training recordings as public domain; the voice repository is labeled MIT. The Piper runtime and model weights are not bundled with BeatTrace. The generated clips were trimmed and level adjusted for beat playback.
