## Decision summary

1. Keep audio models and DSP out until their implementation phases; install only a focused browser media parser for Phase 2.
2. Use browser-local playback and analysis as the default architecture. No audio is uploaded by this app.
3. Build analysis behind a normalized provider contract so models and DSP can be swapped.
4. Defer Essentia until its AGPL/commercial terms and exact model licensing are resolved for intended distribution.
5. Defer Demucs until checkpoint rights and local resource requirements are reviewed.
6. Use the optional BeatNet local adapter for beat/downbeat analysis. Basic Pitch remains deferred for later melody work.

## Phase 5 update

BeatNet is integrated as an optional local-only adapter. The browser app continues to perform traditional DSP by default; choosing “Try local AI” checks `127.0.0.1` and only then sends the selected file to the local bridge. No cloud endpoint is used. The bridge is separate because BeatNet needs Python/PyTorch plus Librosa and Madmom; these dependencies are not added to the browser bundle. The upstream repository currently describes v1.2.0, Python/PyTorch, 22050 Hz input for waveform calls, and paired beat/bar-position output. Its repository is marked CC-BY-4.0; checkpoint provenance and redistribution terms still need review, so no checkpoints are bundled. [Official README](https://github.com/mjhydri/BeatNet), [official setup metadata](https://github.com/mjhydri/BeatNet/blob/main/setup.py).

BeatNet does not publish a calibrated confidence score in its documented output. The adapter derives a timing-consistency estimate from the returned beat intervals and declines results below a conservative threshold. The UI labels this as an estimate, not as BeatNet confidence. Exact model weights and package version are reported by the local service at runtime.

BeatNet 1.2.0 is installed in the isolated `beattrace-beatnet` environment and the loopback service has been exercised by the frontend adapter. A three-track comparison and sample timings are recorded in `phase-5-validation.md`; the small sample and estimated confidence behavior remain limitations.
